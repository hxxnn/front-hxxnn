# 대시보드 기본 구성

대시보드, 관리 화면, 현황 요약 화면을 만들 때의 기본 구성이다. 주제(가계부, 매출, 운동, 서버 상태 등)와 상관없이 이 뼈대를 쓰고, 주제에 따라 바꾸는 것은 **포인트 색, 카드 안의 내용, 문구**뿐이다. 사용자가 다른 구조를 직접 요청하면 그 요청이 우선한다. 기존 프로젝트에 적용할 때는 구조를 바꾸지 말고 이 문서의 스타일 규칙만 입힌다.

## 1. 전체 구조 (데스크톱)

```
┌────┐  ┌──────────────────────────────────────────────┐
│레일│  │ 상단 바 (떠 있는 유리 바, 고정)                 │
│    │  └──────────────────────────────────────────────┘
│    │  ┌──────────────────────────────────────────────┐
│    │  │ 큰 유리 패널                                    │
│    │  │  인사말 + 한 줄 요약                            │
│    │  │  ┌─────────┐ ┌──────────────────────────────┐ │
│    │  │  │ 핵심 수치 │ │ 추이 차트                      │ │
│    │  │  └─────────┘ └──────────────────────────────┘ │
│    │  │  ┌─────────┐ ┌──────────────────────────────┐ │
│    │  │  │ 목표·한도 │ │ 최근 활동 표 (검색·필터)        │ │
│    │  │  └─────────┘ └──────────────────────────────┘ │
└────┘  └──────────────────────────────────────────────┘
```

1. **아이콘 레일 (왼쪽)**
   - 폭 56px 안팎의 얇은 유리 세로 바. 아이콘 버튼은 40px.
   - 항목은 섹션 이동 링크, 주 행동(채워진 원형 버튼 하나), 맨 아래 다크/라이트 전환.
   - 화면 맨 위가 아니라 **큰 패널의 시작선에 맞춰 아래로 내려** 놓는다. 스크롤하면 상단 바 바로 아래에 고정된다.
   - 아이콘만 있으므로 `aria-label`과 `title`을 반드시 둔다.
2. **상단 바**
   - 큰 패널 위에 따로 떠 있는 얇은 유리 바(높이 56px, 완전히 둥근 모서리). 위쪽에 고정(sticky).
   - 왼쪽은 현재 맥락(날짜, 기간, 현재 위치), 오른쪽은 상태 알약 하나(예: 한도 사용률). 메뉴를 넣지 않는다.
   - 화면 맨 위가 바로 내용에 달라붙는 느낌을 막는 역할이다.
3. **큰 유리 패널 하나**
   - 안에 인사말(시간대에 맞는 문장)과 한 줄 요약을 두고, 그 아래에 카드 그리드를 둔다.
4. **카드는 4~5개 안에서 끝낸다.** 정보를 더하고 싶으면 카드를 늘리기 전에 기존 카드에 합칠 수 있는지 먼저 본다.
   - **핵심 수치 카드**: 대표 숫자(48px 이상, 화면에 하나), 한 줄 상태 칩, 보조 지표 2개(포인트 색으로 채운 블록 + 중립 블록), 주 버튼(검정)과 보조 버튼(흰색) 한 쌍.
   - **추이 차트 카드**: 최근 기간 비교. 두 시리즈면 포인트 색과 강한 중립색(검정)으로 구분한다.
   - **목표·한도 카드**: 입력 가능한 목표값, 진행 막대, 남은 양을 알려 주는 한 문장.
   - **최근 활동 표 카드**: 검색창, 전체/항목별 필터, 스크롤 영역, 상태는 점과 글자로 표시.

## 2. 그리드

```css
.board { display: grid; gap: 16px; grid-template-columns: minmax(0, 1fr);
         grid-template-areas: "kpi" "chart" "goal" "table"; }
@media (min-width: 1000px) {
  .board { grid-template-columns: minmax(300px, .8fr) minmax(0, 1.5fr);
           grid-template-areas: "kpi chart" "goal table"; }
}
```

- 모바일에서는 한 열로 쌓고, 왼쪽 레일은 화면 아래에 떠 있는 유리 탭바(아이콘 + 짧은 라벨)로 바꾼다. 탭바가 가리지 않도록 아래 여백을 둔다.
- 같은 행의 카드는 높이를 맞춘다(stretch). 남는 공간이 어색하면 카드 안에 내용을 채우지 말고 배치를 먼저 조정한다.

## 3. 유리와 카드 (유리 위에 유리를 겹치지 않는다)

- **유리**: 레일, 상단 바, 큰 패널, 모바일 탭바, 알림에만 쓴다.
- **안쪽 카드**: 평평한 반투명 면(`--card`)이다. 블러를 걸지 않는다.
- 그림자는 위쪽 광원 하나. 위쪽 하이라이트 한 줄 + 가장자리 선 한 줄 + 바깥 그림자 한 겹이 전부다. 높이 단계는 둘(큰 요소 / 카드).
- 배경은 도형 없는 단일 그라데이션이다.

## 4. 색 토큰

```css
:root {                       /* 다크 */
  --bg-grad: linear-gradient(165deg, #10242A 0%, #0B161B 55%, #0A1216 100%);
  --ink: #EAF4F2; --ink-2: rgba(234,244,242,.74); --ink-3: rgba(234,244,242,.56);
  --accent: /* 주제에서 고른 포인트 색 */;  --on-accent: /* 그 위의 글자색 */;
  --strong: #EAF4F2; --on-strong: #0A1216;          /* 주 버튼·대비 시리즈 */
  --card: rgba(255,255,255,.07); --well: rgba(255,255,255,.07); --well-2: rgba(255,255,255,.12);
}
:root[data-theme="light"] {   /* 라이트 */
  --bg-grad: linear-gradient(165deg, #E6F0EE 0%, #EFF5F4 55%, #F4F7F7 100%);
  --ink: #0D1F1D; --strong: #0F1413; --on-strong: #FFFFFF;
  --card: rgba(255,255,255,.66); --well: rgba(13,31,29,.05); --well-2: rgba(13,31,29,.09);
}
```

- 색은 **포인트 1 + 강한 중립 1 + 흰색/회색** 세 가지 역할로 쓴다. 포인트 색의 색상은 주제에서 고르고(예: 가계부는 초록), 나머지 역할은 그대로 둔다.
- 포인트 색은 긍정/핵심(수입, 달성, 진행)에만 쓴다. 검정(다크에서는 밝은 색)은 주 버튼과 대비 시리즈에 쓴다.
- 라이트 모드에서 포인트 색 위의 흰 글자는 4.5:1 이상이 되도록 포인트 색을 어둡게 고른다.

## 5. 차트와 표

- 막대 두께 24px 이하(두 시리즈는 각 14px 안팎), 윗부분만 4px 둥글게, 밑은 직각.
- 눈금은 `0 / 100만 / 200만`처럼 깔끔한 값으로, 격자선은 1px 실선으로 아주 옅게.
- 시리즈가 둘이면 범례가 항상 있다. 막대에 마우스를 올리거나 키보드로 포커스하면 툴팁이 뜨고, "표로 보기" 전환이 있다.
- 값을 막대마다 다 붙이지 않는다. 툴팁과 표가 담당한다.
- 샘플 데이터가 섞여 있으면 화면에 "예시 데이터"라고 표시한다.
- 표는 가로 스크롤을 허용하고, 검색 결과가 없을 때는 "조건에 맞는 내역이 없어요. 검색어나 필터를 바꿔 보세요."처럼 해결 방법을 안내한다.

## 6. 인터랙션

- 쓰는 것: 지출/수입 같은 전환 슬라이더, 누르면 눌리는 반응, 한도 입력에 따라 진행 막대·상단 알약·차트가 함께 바뀌는 연동, 삭제 후 되돌리기.
- 쓰지 않는 것: 마우스를 따라다니는 효과, 배경에서 저절로 움직이는 요소, 카드마다 붙는 호버 장식.

## 7. 체크리스트

- 대표 숫자가 화면에서 가장 먼저 보이는가(48px 이상, 하나뿐인가).
- 카드가 5개를 넘지 않는가. 합칠 수 있는 카드를 합쳤는가.
- 유리가 레일·상단 바·패널·탭바에만 쓰였는가(카드에 블러가 없는가).
- 색이 포인트 1 + 강한 중립 + 중립으로 끝나는가.
- 상단 바와 레일이 서로 다른 높이에서 시작해 패널과 선이 맞는가.
- 다크/라이트 모두 대비를 확인했는가. 모바일 폭에서 탭바가 내용을 가리지 않는가.
- 샘플 데이터에 "예시" 표시가 있는가.
