# 대시보드 기본 구성

대시보드, 관리 화면, 현황 요약 화면을 만들 때의 기본 구성이다. 주제(가계부, 매출, 운동, 서버 상태 등)와 상관없이 이 뼈대를 쓰고, 주제에 따라 바꾸는 것은 **포인트 색, 카드 안의 내용, 문구**뿐이다. 사용자가 다른 구조를 직접 요청하면 그 요청이 우선한다. 새로 만들 때는 이 문서를 구현한 `assets/dashboard-template.html`을 복사해 `CONFIG`만 바꾼다. 기존 프로젝트에 적용할 때는 구조를 바꾸지 말고 이 문서의 스타일 규칙만 입힌다.

## 1. 전체 구조 (데스크톱)

```
┌────┐  ┌──────────────────────────────────────────────┐
│레일│  │ 상단 바 (떠 있는 유리 바, 고정)                 │
│    │  └──────────────────────────────────────────────┘
│    │  ┌──────────────────────────────────────────────┐
│    │  │ 큰 유리 패널                                    │
│    │  │  인사말 + 한 줄 요약                            │
│    │  │  ┌─────────┐ ┌──────────────────────────────┐ │
│    │  │  │ 핵심 수치 │ │ 추이 차트                      │ │
│    │  │  └─────────┘ └──────────────────────────────┘ │
│    │  │  ┌─────────┐ ┌──────────────────────────────┐ │
│    │  │  │ 목표·한도 │ │ 최근 활동 표 (검색·필터)        │ │
│    │  │  └─────────┘ └──────────────────────────────┘ │
└────┘  └──────────────────────────────────────────────┘
```

1. **아이콘 레일 (왼쪽)**
   - 폭 68px 칸에 **유리 알약 하나**(`.rail-nav`, 모서리 36px, 안쪽 여백 10px 8px)를 세운다. 아이콘 버튼은 **44px 원형**이고 간격은 6px.
   - 알약 안에는 섹션 이동 링크와 주 행동(포인트 색으로 채운 원형 버튼 하나)을 둔다. 맨 아래, 알약 바깥에는 **색상 설정 버튼(팔레트 아이콘)** 을 둔다(아래 "색상 설정 패널").
   - **선택 표시는 액체 물방울**이다(`assets/rail-goo.js`, 자세한 사용법은 `references/rail-goo.md`). 스크롤 위치를 따라 현재 구역을 표시하고, 물방울이 메뉴 사이를 늘어났다 맺히며 옮겨 간다. 레일 가까이 마우스를 가져가면 그쪽으로 부푼다(스킬의 "마우스 효과 금지" 원칙에서 이 물방울만 예외다).
   - 아이콘 이름은 마우스를 올리면 오른쪽에 말풍선(`data-tip`)으로 보인다. 아이콘만 있으므로 `aria-label`과 `data-tip`을 반드시 둔다. 선택된 항목에는 `aria-current="location"`.
   - 올려 보면 아이콘이 살짝 떠오르며 커지고(translateY -2px, scale 1.1), 누르면 눌렸다 돌아온다.
   - 화면 맨 위가 아니라 **큰 패널의 시작선에 맞춰 아래로 내려** 놓는다. 스크롤하면 상단 바 바로 아래에 고정된다.
   - `rail-goo.js`가 없거나 WebGL이 안 되면 선택된 버튼이 채움색(`--strong`)으로 칠해지는 것으로 대신한다. 900px 미만에서는 물방울을 쓰지 않는다.
2. **상단 바**
   - 큰 패널 위에 따로 떠 있는 얇은 유리 바(높이 56px, 완전히 둥근 모서리). 위쪽에 고정(sticky).
   - 왼쪽은 현재 맥락(날짜, 기간, 현재 위치), 오른쪽은 상태 알약 하나(예: 한도 사용률). 메뉴를 넣지 않는다.
   - 화면 맨 위가 바로 내용에 달라붙는 느낌을 막는 역할이다.
3. **큰 유리 패널 하나**
   - 안에 인사말(시간대에 맞는 문장)과 한 줄 요약을 두고, 그 아래에 카드 그리드를 둔다.
4. **카드는 4~5개 안에서 끝낸다.** 정보를 더하고 싶으면 카드를 늘리기 전에 기존 카드에 합칠 수 있는지 먼저 본다.
   - **핵심 수치 카드**: 대표 숫자(48px 이상, 화면에 하나), 한 줄 상태 칩, 보조 지표 2개(포인트 색으로 채운 블록 + 중립 블록), 주 버튼(검정)과 보조 버튼(흰색) 한 쌍.
   - **추이 차트 카드**: 최근 기간 비교. 두 시리즈면 포인트 색과 강한 중립색(검정)으로 구분한다.
   - **목표·한도 카드**: 입력 가능한 목표값, 진행 막대, 남은 양을 알려 주는 한 문장.
   - **최근 활동 표 카드**: 검색창, 전체/항목별 필터, 스크롤 영역, 상태는 점과 글자로 표시.

## 2. 그리드

```css
.board { display: grid; gap: 16px; grid-template-columns: minmax(0, 1fr);
         grid-template-areas: "kpi" "chart" "goal" "table"; }
@media (min-width: 1000px) {
  .board { grid-template-columns: minmax(300px, .8fr) minmax(0, 1.5fr);
           grid-template-areas: "kpi chart" "goal table"; }
}
```

- 모바일에서는 한 열로 쌓고, 왼쪽 레일은 화면 아래에 떠 있는 유리 탭바(아이콘 + 짧은 라벨)로 바꾼다. 탭바가 가리지 않도록 아래 여백을 둔다.
- 같은 행의 카드는 높이를 맞춘다(stretch). 남는 공간이 어색하면 카드 안에 내용을 채우지 말고 배치를 먼저 조정한다.

## 3. 유리와 카드 (유리 위에 유리를 겹치지 않는다)

- **유리**: 레일, 상단 바, 큰 패널, 모바일 탭바, 알림에만 쓴다.
- **안쪽 카드**: 평평한 반투명 면(`--card`)이다. 블러를 걸지 않는다.
- 그림자는 위쪽 광원 하나. 위쪽 하이라이트 한 줄 + 가장자리 선 한 줄 + 바깥 그림자 한 겹이 전부다. 높이 단계는 둘(큰 요소 / 카드).
- 배경은 도형 없는 단일 그라데이션이다.

## 4. 색 토큰

```css
:root {                       /* 다크 */
  --bg-grad: linear-gradient(165deg, #10242A 0%, #0B161B 55%, #0A1216 100%);
  --ink: #EAF4F2; --ink-2: rgba(234,244,242,.74); --ink-3: rgba(234,244,242,.56);
  --accent: /* 주제에서 고른 포인트 색 */;  --on-accent: /* 그 위의 글자색 */;
  --strong: #EAF4F2; --on-strong: #0A1216;          /* 주 버튼·대비 시리즈 */
  --card: rgba(255,255,255,.07); --well: rgba(255,255,255,.07); --well-2: rgba(255,255,255,.12);
}
:root[data-theme="light"] {   /* 라이트 */
  --bg-grad: linear-gradient(165deg, #E6F0EE 0%, #EFF5F4 55%, #F4F7F7 100%);
  --ink: #0D1F1D; --strong: #0F1413; --on-strong: #FFFFFF;
  --card: rgba(255,255,255,.66); --well: rgba(13,31,29,.05); --well-2: rgba(13,31,29,.09);
}
```

- 색 값은 `scripts/derive-palette.js`로 배경색·강조색에서 계산해 쓴다(SKILL.md 11번). 아래 값은 그 예시다.
- 코드에서는 색 이름이 아니라 **역할 이름의 변수**를 쓴다: `--accent`(채움·막대·아이콘), `--accent-text`(글자로 쓸 때), `--on-accent`(강조색 위 글자), `--strong`/`--on-strong`, `--card`, `--well`. 이렇게 해야 팔레트를 바꿀 때 변수 값만 갈아끼우면 된다. 강조색을 글자로 쓰는 곳(예: 수입 금액)에는 `--accent`가 아니라 `--accent-text`를 쓴다.
- 색은 **포인트 1 + 강한 중립 1 + 흰색/회색** 세 가지 역할이 기본 틀이다. 이 틀의 개수(세 가지)는 지키되, **역할 배분은 주제에 맞게 바꿀 수 있다.** 포인트 색의 색상도 주제에서 고른다(예: 가계부는 초록).
- 기본 배분: 포인트 색은 긍정/핵심(수입, 달성, 진행)에, 강한 중립(검정, 다크에서는 밝은 색)은 주 버튼과 대비 시리즈에 쓴다.
- 주제에 따라 바꾸는 예: 서버 상태처럼 "문제"가 핵심인 화면은 포인트 색을 경고 쪽 신호에 배정하고 정상 상태는 중립으로 둔다. 목표 달성이 핵심인 화면은 주 버튼도 포인트 색으로 채울 수 있다.
- 배분을 바꿔도 지켜야 할 것: 색을 넷 이상으로 늘리지 않는다. 한 색은 한 가지 의미에만 쓰고, 화면 전체에서 같은 역할에 같은 색을 쓴다. 색만으로 의미를 전하지 않고 글자·아이콘·모양을 함께 쓴다.
- 라이트 모드에서 포인트 색 위의 흰 글자는 4.5:1 이상이 되도록 포인트 색을 어둡게 고른다.

## 4-1. 색상 설정 패널 (기본으로 넣는다)

레일 맨 아래의 팔레트 버튼을 누르면 레일 옆(모바일은 탭바 위)에 유리 패널이 열린다. 다크/라이트 전환은 이 패널이 대신한다.

- **추천 조합**: 배경색 + 강조색 쌍을 원형 견본 8개 안팎으로 보여 준다(예: 초록·보라·파랑·주황의 다크/라이트). 각 견본은 이름이 글자로 붙고, 선택된 것은 테두리와 굵은 글자로 표시한다. 추천 조합은 모두 `scripts/derive-palette.js`를 통과한 값만 쓴다.
- **직접 고르기**: 배경색, 강조색 색상 선택기(`input type="color"`)와 현재 색 값(hex)을 보여 준다. 바꾸는 즉시 화면에 적용한다.
- **모드는 자동**: 배경 밝기로 다크/라이트를 정한다. 패널에 "배경이 밝으면 라이트, 어두우면 다크로 바뀌어요"라고 안내한다.
- **대비 검사 상태**: 패널 안에 검사 결과를 한 줄로 알린다. 모두 통과하면 "대비 검사를 모두 통과했어요.", 실패가 있으면 항목과 수치를 함께 알리고 색을 조금 바꿔 보라고 안내한다(`role="status"`). 사용자가 고른 색을 말없이 바꾸지 않는다.
- **저장과 초기화**: 선택은 `localStorage`에 저장하고, 깜빡임이 없도록 `<head>`에서 먼저 적용한다. "기본 색으로" 버튼으로 되돌린다. 저장값이 없으면 시스템 설정(`prefers-color-scheme`)에 맞는 기본 조합을 쓴다.
- **계산**: 페이지 안에 `derive-palette.js`와 같은 계산(글자·카드·면 색, 강조색 글자 보정)을 넣어 색이 바뀔 때마다 CSS 변수를 갱신한다. 유리 질감의 하이라이트·그림자는 모드(다크/라이트)에 따라 두 벌을 둔다.
- **접근성**: 버튼은 `aria-haspopup="dialog"`, `aria-expanded`를 갖고, 열면 첫 견본으로 포커스가 가고, Esc나 바깥 클릭으로 닫히며 닫으면 버튼으로 포커스가 돌아온다.

## 5. 차트와 표

- 막대 두께 24px 이하(두 시리즈는 각 14px 안팎), 윗부분만 4px 둥글게, 밑은 직각.
- 눈금은 `0 / 100만 / 200만`처럼 깔끔한 값으로, 격자선은 1px 실선으로 아주 옅게.
- 시리즈가 둘이면 범례가 항상 있다. 막대에 마우스를 올리거나 키보드로 포커스하면 툴팁이 뜨고, "표로 보기" 전환이 있다.
- 값을 막대마다 다 붙이지 않는다. 툴팁과 표가 담당한다.
- 샘플 데이터가 섞여 있으면 화면에 "예시 데이터"라고 표시한다.
- 표는 가로 스크롤을 허용하고, 검색 결과가 없을 때는 "조건에 맞는 내역이 없어요. 검색어나 필터를 바꿔 보세요."처럼 해결 방법을 안내한다.

## 6. 인터랙션

- 쓰는 것: 지출/수입 같은 전환 슬라이더, 누르면 눌리는 반응, 한도 입력에 따라 진행 막대·상단 알약·차트가 함께 바뀌는 연동, 삭제 후 되돌리기.
- 쓰지 않는 것: 마우스를 따라다니는 효과, 배경에서 저절로 움직이는 요소, 카드마다 붙는 호버 장식. 단 레일의 선택 물방울(`rail-goo.js`)이 마우스 쪽으로 부푸는 것은 예외로 허용한다.

## 7. 체크리스트

- 대표 숫자가 화면에서 가장 먼저 보이는가(48px 이상, 하나뿐인가).
- 카드가 5개를 넘지 않는가. 합칠 수 있는 카드를 합쳤는가.
- 유리가 레일·상단 바·패널·탭바에만 쓰였는가(카드에 블러가 없는가).
- 색이 포인트 1 + 강한 중립 + 중립으로 끝나는가.
- 상단 바와 레일이 서로 다른 높이에서 시작해 패널과 선이 맞는가.
- 레일의 선택 표시가 스크롤 위치와 맞고, 물방울 글자(아이콘) 대비가 읽히는가(`--goo-color` 위에 `--on-strong`).
- 색상 설정 패널이 있고, 추천 조합이 모두 대비 검사를 통과하는가. 배경이 바뀌어도 글자와 카드가 읽히는가.
- 모바일 폭에서 탭바와 상단 바가 화면 밖으로 넘치거나 내용을 가리지 않는가.
- 샘플 데이터에 "예시" 표시가 있는가.
